# 途见锦官 · 智能体大赛策划方案

2026 全球智能体大赛（1010 数字人节）**赛道 A · 高校组**选题与多智能体协同策划。

主推方向：**文商旅**。作品概念是在智小途上建一个空间，放入 **12 个职责不同、必须互相交接** 的智能体，共用一块行程白板，同时服务游客和商户。

## 下载到电脑

- 离线网页：打开 `downloads/途见锦官策划方案.html` 或站点里的「下载离线网页」，用浏览器直接打开，不需要安装 Node。
- 完整源码：解压 `tujian-jinguan-source.zip` 后执行 `npm install` 和 `npm run dev`。
- 也可以先点对话里的 **Create repo** 创建仓库，再在自己电脑上 `git clone`。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:43127](http://127.0.0.1:43127)。

## 方案怎么用

1. 在本站读完整策划：选题理由、十二岗名片、协同事件、演示剧本、知识库、十三天排期。
2. 到 [智小途](https://workbrain.cn/chat/) 按「十二岗」创建智能体空间。
3. 按 [官方报名页](https://di.workbrain.cn/webapp/r3vh7NpFy9qm64ke/17/releases/) 在 **2026-09-20 24:00** 前交齐材料。

## 技术

Next.js、TypeScript、Tailwind CSS、shadcn/ui。策划正文在 `src/data/plan.ts`。
