## 可复制正文

### 空间名称

```
江城灯语
```

### 空间描述（主推）

```
武汉夜里，两江的灯还亮着。提灯向导在江边等你，十二位旅伴把黄鹤楼、过早、夜市、汉街和游记接成一程——你只管问，路在灯里。
```

若输入框字数更紧，用短版：

```
提灯问江城。十二位旅伴陪你登黄鹤、去过早、约灯光秀、找老字号、把热干面写进游记。
```

### 空间域名

主选：

```
jiangchengyu
```

被占用时按序试（均为 4–20 位小写字母）：

```
jiangchengdeng
wuhandengyu
heloyu12
whdengyu
```

创建后完整入口：`https://<域名>.workbrain.cn`（以平台实际跳转为准）。

### 空间地理位置

```
湖北省武汉市
```

定位更细时可搜：

```
湖北省武汉市武昌区黄鹤楼
```

### 空间行业类型

```
文化旅游
```
