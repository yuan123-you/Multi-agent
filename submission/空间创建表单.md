对照自定义创建弹窗，可直接复制。文案与视觉均按本仓库《地方文商旅协同空间》设计（A 赛道，12 个有效智能体，文商旅闭环）。

区县名称一旦由赛区确认，先改本文件中带「地方」的字段与域名备选，再同步 `A赛道-设计文档.txt`、`A赛道-作品简介.txt` 与详细设计标题。

## 逐项填写

| 表单字段 | 填写值 | 说明 |
| --- | --- | --- |
| 空间名称 | `地方文商旅协同空间` | 必填。不要加书名号。锁定区县后把「地方」换成区县名，例如「大邑文商旅协同空间」。 |
| 空间描述 | 见下方「主推描述」 | 必填。面向广场访客与评审，不写赛制套话。 |
| 空间域名 | `difangwenlv` | 必填。仅 4–20 位数字或小写字母，完整地址为 `difangwenlv.workbrain.cn`。被占用则按备选往下试。 |
| 空间地理位置 | 赛区指定区县的行政地名 | 点右侧定位，搜「省 + 市 + 区县」，可再加景区名。未锁区县前不要用课件里的「西岭雪山」当最终选题。 |
| 空间行业类型 | `文化旅游` | 下拉里若无此项，选最接近的「旅游」或「文旅」。 |
| logo | `assets/space-logo-4x1.png` | 必填。成品 **2000×500（4:1）**，与弹窗「推荐比例 4:1」一致。 |
| 头像 | `assets/space-avatar-800.png` | 必填。成品 **800×800**，3D 数字导游形象，与入口讲解员人设一致。 |
| 公开到智小途广场 | **打开** | 评审要在线预览；综合分含公众投票。打开后所有人可申请加入。 |

## 可复制正文

### 空间名称

```
地方文商旅协同空间
```

### 空间描述（主推）

```
面向同一地方文商旅场景的智能体协同空间。以定制3D数字导游为入口，12位专业智能体按角色分区服务，共同完成问景点、排行程、约活动、找商户、记游记。
```

若输入框字数更紧，用短版：

```
12智能体服务地方文商旅：数字导游入口，问景点、排行程、约活动、找商户、记游记。
```

### 空间域名

主选：

```
difangwenlv
```

被占用时按序试（均为 4–20 位小写字母）：

```
wenlvcoop
wenshanglv
localwenlv
wenlv12space
```

创建后完整入口：`https://<域名>.workbrain.cn`（以平台实际跳转为准）。

### 空间地理位置

格式示例（把××换成赛区指定地名）：

```
四川省××市××县
```

未锁区县、又必须先建空间时，可先填队伍所在城市，锁定后到空间设置里改成精确区县。不要填「全国」或空泛的「中国」。

### 空间行业类型

```
文化旅游
```
