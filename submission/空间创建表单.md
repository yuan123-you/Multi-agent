不用「灯语」：那是从图标灯笼倒推的词，不是武汉语汇，广场上也不好懂。

## 可复制正文

### 空间名称

```
江城知音
```

若更想直白，备用名：`江城问途`（好懂）、`三镇问途`（武昌汉口汉阳）、`鹤楼问途`（一听就是武汉）。

### 空间描述（主推）

先贴这一段。若输入框截断，再用下面的中版 / 短版。

```
江城知音，一座会说话的武汉。第一次来、带家人、来过早或赶夜游，都可以从数字导游走进武昌、汉口、汉阳。十二位知音按事儿分工、不互相抢话：有人讲黄鹤楼、东湖樱花、古琴台和汉绣楚剧；有人懂户部巷过早、热干面、豆皮和老字号；有人帮你排半日到两日行程，看地铁、轮渡和住宿；有人约长江灯光秀、夜游和节庆；有人带你逛汉街、江汉路，找商户与文创。遇走失或暴雨也能问，外语可以请翻译，晚上把当天写成游记。问景点、排行程、约活动、找商户、记游记，在同一座空间走完，不必再把攻略拆成五个App。
```

中版（约120字）：

```
江城知音是一座能对话的武汉。数字导游站在两江边，把你交给十二位知音：登黄鹤、听非遗、去过早、排行程、坐地铁、约灯光秀、逛汉街、找老字号、遇应急、帮翻译、写游记。三镇怎么走、热干面去哪吃、夜游怎么约，你问一句，江城答一句。
```

短版（约50字）：

```
江城有伴。十二位知音陪你登黄鹤、去过早、约灯光秀、找老字号、把热干面写进游记。
```
