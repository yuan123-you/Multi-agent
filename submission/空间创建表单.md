# 智小途云「创建空间」表单填写稿

对照自定义创建弹窗，可直接复制。场景锁定 **武汉**。空间对外名称用 **江城知音**（古琴台「知音」典故 + 十二位旅伴），报名作品名写《武汉文商旅协同空间》。

不用「灯语」：那是从图标灯笼倒推的词，不是武汉语汇，广场上也不好懂。

## 可复制正文

### 空间名称

```
江城知音
```

若更想直白，备用名：`江城问途`（好懂）、`三镇问途`（武昌汉口汉阳）、`鹤楼问途`（一听就是武汉）。

### 空间描述（主推）

```
两江之间，遇十二知音。他们讲黄鹤、排一日、约灯光秀、找老字号，把热干面写进游记——你问一句，江城答一句。
```

若输入框字数更紧，用短版：

```
江城有伴。十二位知音陪你登黄鹤、去过早、约夜游、找老字号、把今天写成游记。
```

### 空间域名

主选：

```
wuhanzhiyin
```

被占用时按序试（均为 4–20 位小写字母）：

```
jiangchengzhiyin
zhiyin12
whzhiyin
jiangchengwt
```

创建后完整入口：`https://<域名>.workbrain.cn`（以平台实际跳转为准）。

### 空间地理位置

```
湖北省武汉市
```

定位更细时可搜：

```
湖北省武汉市武昌区黄鹤楼
```

### 空间行业类型

```
文化旅游
```
