# 智小途云「创建空间」表单填写稿

对照自定义创建弹窗，可直接复制。空间对外名称用品牌名 **青峦灯语**（提灯向导 + 十二旅伴），报名作品名仍可写《地方文商旅协同空间》。

区县锁定后，地理位置改成真实区县即可；品牌名不必改成「××文商旅协同空间」，避免再变回公文腔。

---

## 逐项填写

| 表单字段 | 填写值 | 说明 |
| --- | --- | --- |
| 空间名称 | `青峦灯语` | 必填。广场上认这个名字。不要加书名号。 |
| 空间描述 | 见下方「主推描述」 | 必填。写给进空间的人听，不写赛制术语。 |
| 空间域名 | `qingluanyu` | 必填。仅 4–20 位数字或小写字母，完整地址为 `qingluanyu.workbrain.cn`。被占用则按备选往下试。 |
| 空间地理位置 | 赛区指定区县的行政地名 | 点右侧定位，搜「省 + 市 + 区县」，可再加景区名。未锁区县前不要用课件里的「西岭雪山」当最终选题。 |
| 空间行业类型 | `文化旅游` | 下拉里若无此项，选最接近的「旅游」或「文旅」。 |
| logo | `assets/space-logo-4x1.png` | 必填。成品 **2000×500（4:1）**，标题为「青峦灯语」。 |
| 头像 | `assets/space-avatar-800.png` | 必填。成品 **800×800**，提灯向导，与入口讲解员人设一致。 |
| 公开到智小途广场 | **打开** | 评审要在线预览；综合分含公众投票。打开后所有人可申请加入。 |

## 可复制正文

### 空间名称

```
青峦灯语
```

### 空间描述（主推）

```
青峦里藏着一座会说话的地方。提灯向导在门口等你，十二位旅伴把风景、行程、夜场、老店和游记接成一程——你只管问，路在灯里。
```

若输入框字数更紧，用短版：

```
提灯问山问市。十二位旅伴陪你讲风景、排一日、约夜游、找老字号、把今天写成游记。
```

### 空间域名

主选：

```
qingluanyu
```

被占用时按序试（均为 4–20 位小写字母）：

```
qingluandeng
yidengyintu
dengyu12
qingluan12
```

创建后完整入口：`https://<域名>.workbrain.cn`（以平台实际跳转为准）。

### 空间地理位置

格式示例（把××换成赛区指定地名）：

```
四川省××市××县
```

未锁区县、又必须先建空间时，可先填队伍所在城市，锁定后到空间设置里改成精确区县。不要填「全国」或空泛的「中国」。

### 空间行业类型

```
文化旅游
```
