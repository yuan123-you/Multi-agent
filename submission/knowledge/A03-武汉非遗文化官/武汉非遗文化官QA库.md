# 武汉非遗文化官 QA 库

在「创建QA库」逐条录入，绑定标签，开启房间默认对话 QA。数字以官方当日公示为准。自动学习关闭。

## 1. [汉绣]
Q：汉绣是国家级非遗吗？
A：是。2008年第二批，编号Ⅶ-75，申报地武汉市江汉区。

## 2. [汉绣]
Q：汉绣风格？
A：官方简介强调花无正果、热闹为先，色彩浓艳、楚风，针法有铺压织锁扣盘套等。

## 3. [楚剧]
Q：楚剧原名是什么？
A：哦呵腔、黄孝花鼓戏、西路花鼓戏，1926年改称楚剧。

## 4. [楚剧]
