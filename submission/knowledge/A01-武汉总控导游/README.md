# A01 武汉总控导游 · 知识包（按官方精选对齐）

对照《验收标准手册》3.2 精选智能体，以及团队详细设计 5.1 / 5.2。上一版只交了 8 篇刚过 800 字的文档，那是**门禁下限**，不是完整精选包。

## 官方与项目要求（精选 A01）

| 项 | 官方/项目口径 | 本目录现状 |
| --- | --- | --- |
| 文档 | ≥8 篇，PDF/Word，**单篇 ≥800 字**，逻辑清楚、非纯堆砌 | **16 篇 Word**，单篇约 900–1400 字 |
| QA | 最低 ≥15；课件精选示例 **50 条**；房间开启对话 QA 并打标签 | **50 条**见 `武汉总控导游QA库.md` |
| 图片 | ≥10 张，JPG/PNG，≥720P，无水印，文件名写主题 | 尚未做（菜单图集另补） |
| 视频 | ≥4 条，MP4，单条 ≥30 秒，≥1080P | 尚未做 |
| 文旅结构 | 景区介绍 / 游玩攻略 / 图集 / 视频；总控另建空间导览 QA | 文档覆盖空间导览 + 三镇/黄鹤楼/东湖/过早/交通/夜游**导诊**，不替代 A02 长文 |
| 自动学习 | 可关；对外以私有知识为准 | **保持关闭** |

结论：只传 8 篇偏少、偏瘦。先把 **16 篇文档 + 50 条 QA** 喂进去，图片和视频仍要另做，否则精选项仍缺。

## 上传顺序

1. 对话知识页点 **上传文档**，上传下列 16 个 `.docx`（不要改成 `1.docx`）。
2. 点 **创建QA库**，按 `武汉总控导游QA库.md` 录入 50 条，绑定文中标签。
3. 开启房间默认对话 QA。**自动学习建议关闭**；若点了「学习目标」被迫要填，见下节，来源不要选「互联网」。
4. 房间菜单能点开资料库文档，便于验收抽查。

## 「添加学习目标」怎么填（可跳过）

详细设计：自动学习可设关键词，但对外仍以私有文档/QA 为准，避免网上过时攻略盖过武汉事实。赛期不必为凑「5000 条专有模型」去开互联网学习。

若弹窗必填，总控只加 1—2 条**一级**：

| 字段 | 填法 |
| --- | --- |
| 学习目标 | 见下方三条，复制一条即可 |
| 级别 | `一级` |
| 学习类型 | 选最接近「知识 / 业务 / 问答」的一项（不要选闲聊、创作） |
| 学习来源 | 优先 `深度研究`；没有把握就 `综合学习`。**不要选「互联网」**。不要选「智能体社交对话」（广场闲聊会污染转派）。 |

学会识别游客意图，并按手册转派到十二位武汉知音，不代替专业角色长篇作答。
