## 1. 赛道约束（必须先满足）

### 1.1 我们是谁、交什么

| 项 | 官方要求 | 本队落地 |
| --- | --- | --- |
| 赛道 | A赛道·智能体搭建赛，高校在校学生，个人或 1—5 人 | 5 人队伍 |
| 核心交付 | **1 个智能体空间链接**，空间内 **≥10 个有效智能体**，支持在线预览 | 1 空间 + **12** 个有效智能体 |
| 报名材料 | 封面图 JPG/PNG；空间链接；演示视频 MP4≤5 分钟；设计文档≤500 字；作品简介≤200 字 | 见第 11 章 |
| 官方一句话 | 围绕一个真实场景，搭出「1 个空间 + 至少 10 个有效智能体」 | 文商旅同一场景闭环 |
| 评分口诀 | **完整 > 花哨；场景闭环 > 智能体数量堆砌** | 禁止互不相关的 10 个闲置智能体 |

门禁（触即失去后续评分资格）：

- 空间内有效智能体不足 10 个
- 抄袭侵权 / 违规敏感内容
- 资质冒用 / 材料造假

专家 100 分构成：技术实现与工程质量 30%（角色、知识库、空间配置与稳定性）＋ 应用价值与场景创新 30% ＋ 创新性与用户体验 25% ＋ 作品呈现与答辩 15%。一等奖原则上 ≥90，二等奖 ≥85，三等奖 ≥80；低于 60 分不具备奖项资格。

最终综合分 = 专家 ×70% ＋ 公众投票 ×30%。答辩入围成绩同此权重；各评审区原则上前 10 队答辩（约 7 分钟展示 + 3 分钟问答）。

### 1.2 为什么选文商旅

参赛指南 A 赛道四类方向均可，文商旅官方闭环是：**导览 / 推荐 / 活动 / 商户服务**。覆盖景点介绍、非遗文化、美食特产、历史文化 IP、全域智慧旅游导览、新消费商业场景。

与平台能力对齐：智能体搭建课件以「西岭雪山」为文旅全流程示例；知识规范中文化旅游模块含景区介绍、游玩攻略、图集、视频、VR 云游、在线购票；验收手册行业模型对文旅强调文化真实性、本地准确性、访客体验、实用价值。

选题原则：真实需求 > 大而全。先锁定一个区县/景区集群，再拆 12 个角色，不要做「全国通吃」的空壳导游。

## 2. 问题、目标与用户

### 2.1 痛点

游客面对碎片攻略时，景点讲解、行程规划、活动预约、商户消费彼此割裂：问完「这是什么」还要另开 App 查路、查吃、查票，无法在同一空间完成一次到访决策。

### 2.2 作品目标

在智小途云（WorkBrain）上交付一个可打开、可对话、可演示的智能体空间：用户进入后由数字导游理解意图并转派，12 个专业智能体共同完成「问景点 → 排行程 → 约活动 → 找商户 → 记游记」。

验收口径上的「有效智能体」至少同时满足：

1. 已加入本空间且可从空间/广场进入对外房间  
2. 有独立命名与角色设定（职责、对象、风格、开场白）  
3. 已喂养本角色私有知识，能就本职问题作答，不串台  
4. 房间可打开，菜单内容可访问  
5. 无侵权、无水印、无导流私下联系方式  

### 2.3 目标用户

- 到访游客（首次到访、家庭、研学）  
- 本地生活消费用户（找店、找活动）  
- 评审专家（按空间链接走主链路）

## 3. 总体架构

### 3.1 平台与模型

按《智能体搭建》产品体系：

- 模型底座：WorkBrain（认知 / 决策 / 记忆、知识注入）  
- 创作与发布：智小途云 / WorkChat（智能体、房间、空间门户）  
- 账号：智小途统一登录；报名平台与账号手机号绑定  

智能体应用模型七要素（搭建课件）：**大脑、形象、角色、知识、能力、任务、社交**。每个有效智能体都按这七项配置，缺一就容易被判「无效」或「凑数」。

### 3.2 空间作为枢纽

空间不是网页包装，而是多智能体协同入口：

- 创建空间（自定义或 OPC 模板）→ 配名称、描述、域名、Logo  
- 配置空间门户（建议文旅用**元宇宙门户**）与移动端门户  
- 添加 12 个智能体为空间成员，指定 **空间讲解员**（总控数字导游）  
- 空间级数据管理：公共知识给讲解员与主对话；角色级知识只喂给对应智能体  
- 能力管理：只开放与文商旅相关的能力（写作、作画、视频、PPT 等），避免能力超市全开导致跑题  

门户三选一对照：

| 类型 | 适用 | 本队建议 |
| --- | --- | --- |
| 传统内容门户 | AI 一键生成模块（如「四川文旅」示例） | 可作备份 |
| 自定义门户 | 外链自己的网站 | 不作为主交付（评审要的是空间链接） |
| 元宇宙门户 | 上传 1920×1080 背景图/视频；配广场、空间、商品、活动；加入智能体并设讲解员 | **主交付**；广场 / 商品 / 活动至少落地一类，建议三类都配浅层可点 |

### 3.3 用户主路径（答辩必须跑通）

```
打开空间链接
  → 元宇宙门户（讲解员打招呼）
  → 问景点/文化  → 景点讲解 / 非遗文化
  → 要一日游     → 行程规划 + 交通住宿 + 出行天气
  → 想吃想买     → 美食特产 + 商户服务 + 新消费导购
  → 有没有活动   → 活动预约
  → 应急/外语    → 应急文明 / 多语翻译
  → 帮忙写游记   → 游记创作（调用写作能力）
```

转派规则：讲解员只做意图识别与介绍，不替代专业角色长答；专业角色超出边界时回指讲解员或点名下一角色。

## 4. 十二个有效智能体（角色拆分）

官方推荐路径第二步是「拆角色」。12 个角色全部服务同一地方文商旅场景，对应导览 / 推荐 / 活动 / 商户四段闭环，外加入口、保障与内容沉淀。

命名规范（验收手册）：简洁清晰，直观反映行业及职能，无歧义、无敏感词。建议格式：`地名＋职能`，例如「××景点讲解员」。

| 编号 | 名称 | 闭环位置 | 服务对象 | 沟通风格 | 核心职责 |
| --- | --- | --- | --- | --- | --- |
| A01 | 总控数字导游 | 入口 / 转派 | 所有用户 | 热情、简短、会指路 | 开场、问清意图、介绍空间栏目、转派到 A02—A12 |
| A02 | 景点讲解员 | 导览 | 到访游客 | 准确、有故事、可核实 | 核心景点、历史沿革、开放时间、票价、禁忌 |
| A03 | 非遗文化官 | 导览 | 文化向游客 | 尊重、有出处 | 非遗项目、传承人故事、体验点、礼仪 |
| A04 | 美食特产顾问 | 推荐 | 餐饮消费 | 具体到店、到品 | 招牌菜、时令、忌口、伴手礼 |
| A05 | 行程规划师 | 推荐 | 停留 0.5—3 日游客 | 结构化、给备选 | 半日/一日/两日路线、季节限定、体力分级 |
| A06 | 交通住宿管家 | 推荐 | 行前用户 | 可执行、标清来源 | 大交通、市内接驳、住宿分区、入住注意 |
| A07 | 商户服务助手 | 商户 | 进店/进馆用户 | 礼貌、促成交但不导流站外私联 | 营业时间、位置、预约规则、售后须知 |
| A08 | 活动预约官 | 活动 | 活动参与者 | 讲清名额与规则 | 节庆、夜游、演出、报名须知 |
| A09 | 新消费导购 | 商户 | 文创/新消费 | 种草但不虚假促销 | 文创、联名、街区消费、合规优惠信息 |
| A10 | 应急文明助手 | 保障 | 全员 | 冷静、短指令 | 走失、天气突变、文明旅游、投诉渠道（仅公开渠道） |
| A11 | 多语翻译官 | 保障 | 外语游客 | 先确认语种再译 | 导览词、菜单、告示的中英（及赛区需要的小语种）对译 |
| A12 | 游记创作助手 | 沉淀 | 结束后用户 | 可生成可改 | 按当日路线生成游记/海报文案，调用空间写作/作画能力 |

每个智能体角色设定必须写全四段（精选标准，可直接当提示词）：

1. 核心职责  
2. 服务对象  
3. 沟通风格与口头禅  
4. 开场白 + 3 条推荐问题（绑定 QA 标签，对外展示）  

边界（减少误触发、避免同质化）：

- A02 不规划全天行程（交给 A05）  
- A04 不处理酒店库存（交给 A06）  
- A07/A09 禁止引导留私人微信、站外付款  
- A10 不替代急救，遇伤病只给官方急救与就近医疗机构公开信息  
- A12 不编造未喂养的景点事实

## 5. 知识体系建设

官方路径第三步「补知识」。喂养原则四条：**真实性、合规性、时效性、多样性**。

### 5.1 分层配额（在完整与工期之间取平衡）

参赛口诀是完整优先。12 个角色若全部按精选配额，工期不可控。本队采用「入口精选 + 全员达标」：

**A01、A02、A04、A07 按精选智能体量化（验收手册 3.2 / 搭建课件对照）：**

- 文档 ≥8 篇，PDF/Word，单篇 ≥800 字，逻辑清晰、非纯 AI 堆砌  
- 图片 ≥10 张，JPG/PNG，≥720P，无水印  
- 视频 ≥4 条，MP4，单条 ≥30 秒，≥1080P  
- QA ≥15 条（课件精选示例写 50 条：这 4 个角色尽量向 50 条靠，最低不少于 15）  
- 开启默认房间对话 QA，每条绑定分类标签；图文配套文字说明  

**其余 8 个角色按非精选量化（验收手册 3.3）：**

- 文档 ≥3 篇，单篇 ≥800 字  
- 图片 ≥4 张，≥720P  
- 视频 ≥1 条，≥30 秒，≥720P（争取 1080P）  
- QA ≥15 条，禁止复制网络万能模板  
- 房间菜单至少可访问：3 文档 + 5 图 + 1 视频  

全员共性：

- 文件名必须写清业务主题，禁止 `1.pdf`、`001.jpg`  
- 禁止跨智能体、跨任务复用同一知识库素材、形象、QA  
- 知识真实准确，无虚假、歧视、过时失效信息  
- 商用素材准备授权；非商用确认来源合法  

### 5.2 文旅知识结构（按搭建课件「文化旅游」模块组素材）

每个与景点相关的角色，知识包尽量覆盖：

1. **景区介绍**：核心景点、历史背景、开放时间与票价  
2. **游玩攻略**：路线、季节限定、特色体验  
3. **景区图集**：四季、美食、服饰（图片带内容描述和标签，支持多模态）  
4. **视频展示**：纪录片/短片，无水印、音画清晰  
5. **VR 云游**（可选）：官方或授权漫游链接，放房间菜单  
6. **在线购票**（可选）：官方购票/预约/酒店链接，禁止三无跳转  

A01 另建「空间导览 QA」：本空间有哪些智能体、怎么转派、主链路怎么走。

### 5.3 数据准备与训练

搭建课件数据准备四步：明确定位 → 数据收集 → 数据清洗 → 数据标注。

操作入口：智能体「数据管理」上传文档/图片/视频；添加 QA 并绑定文件标签。空间级也可建 QA 库并「训练大脑」，训练后用于空间主对话及空间内自建智能体。自动学习可设关键词，但对外回答仍以私有知识为准，避免网上过时信息覆盖本地事实。

建议训练集：平台写「专有模型不少于 5000 条」——赛期内达不到就不要硬训；用高质量 QA + 文档喂养保证主链路正确即可。

## 6. 数字人形象与房间视觉

### 6.1 形象策略

精选形象标准：边缘无锯齿、背景干净、发丝服饰清晰；动作口型同步、无跳帧；风格与职业统一。

制作流程（《数字人形象制作操作文档》＋搭建课件第 5 章）必须按序：

1. **工具**：PS2022 抠图；AE2022 绿幕；AI 出图/出视频（即梦、可灵、海螺或智小途「创意作画」「视频生成」）  
2. **出原图**：提示词写明 3D 卡通、职业、全身、C4D/3D 渲染；背景色与形象可分离  
3. **PS 抠主体 + 绿幕**：复制图层 → 选择主体 → 选择并遮住 → 净化颜色 → 纯色绿幕导出  
4. **AI 出两段绿幕视频**：动态说话（固定镜头、开口、眨眼、手自然摆动、不做运镜）；静态待机（微笑、眨眼、身体稳定）  
5. **AE KeyLight(1.2) 抠绿**：切透明网格；导出 QuickTime，通道 **RGB+Alpha**；合成建议 750×1172  
6. **PS 存为 Web 所用格式**：杂边「无」；**全身 GIF 750×1172**；**半身头像 800×800**  
7. **上传打包**：半身头像 ＋ 动态全身 GIF ＋ 静态全身 GIF；角色形象编辑处上传，等审核  

本队形象分工：

- **A01 必须定制**（入口数字人，答辩第一眼）  
- A02 / A04 / A07 有余力则定制，否则用系统内置动态形象，但风格必须与职能统一  
- 其余角色可用内置形象  

Logo/水印必须在抠图阶段去掉。

### 6.2 房间与门户尺寸

| 素材 | 尺寸 | 说明 |
| --- | --- | --- |
| Web 背景 | 1920×1080（16:9） | 清晰无水印，与角色统一 |
| 移动端背景 | 750×1624 | 与 Web 同一套视觉语言 |
| 菜单图标 | 300×300 | 可 AI 生成或合规素材 |
| 元宇宙门户背景 | 图片 1920×1080；视频 mp4/avi/flv/mkv | 文旅氛围，无侵权 |

房间配置：开启对话知识与默认 QA；菜单栏目清晰（简介、资料库、图片、视频等）且可点开；精选角色绑定 **至少 1 项垂直场景特色 Skill**（禁止空白模板、禁止复用其他任务成套 Skill）。对话内 Skill 触发：精选要求召回率 ≥85%、精确率 ≥90%。非精选至少能稳定触发、无报错闪退。

能力建议（贴合文商旅，避免乱绑）：

- A01：空间导览类  
- A05：行程结构化输出  
- A12：AI 写作 / 创意作画  
- A08：活动说明模板  
- 全空间：不要开与医疗处方、投资理财相关的能力

## 7. 空间搭建步骤（对照官方操作）

1. 注册登录 `https://workbrain.cn/chat/`（手机验证码）  
2. 先做 A01：名称、声音、特征、角色设定、开场白、形象  
3. 数据管理喂养 A01 知识与 QA，配置对外房间（主题背景、菜单、能力、任务）  
4. 头像下拉 → 创建新空间（建议 OPC 文旅模板 + 再改）  
5. 配空间名称《地方文商旅协同空间》、描述、域名、Logo、头像（可复制字段与成品图见 `submission/空间创建表单.md`）  
6. 空间数据管理上传公共导览资料；可选训练空间大脑  
7. 新建元宇宙门户：上传背景；添加 12 个智能体；设 A01 为讲解员；配置广场、商品、活动至少一个模块  
8. 同步移动端门户  
9. 空间管理 → 智能体管理：确认 12 个均在架、可点进房间  
10. 导览管理：做 1 条「普通导览」或「流程导览」，与主链路一致，便于演示  
11. 成员管理：五人全部加入；仅队长/空间管理员改门户，避免误删  
12. 分享空间链接，用未登录小号测一遍在线预览  

空间高级管理删除有 24 小时可撤回——赛期禁止删除空间。
